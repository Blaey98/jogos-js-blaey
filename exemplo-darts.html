🎯 Exemplo: Darts no Template Personalizado

✅ Agora funcionando!
Quando você clicar no jogo Darts da lista, ele abrirá no template vertical personalizado em vez de ir diretamente para a URL do Gamezop.

🎮 Teste o Jogo Darts

Clique no botão abaixo para ver o jogo Darts carregado no template personalizado:

📋 Como Funciona

Antes: Clique no jogo → Abre URL do Gamezop diretamente

Agora: Clique no jogo → Abre template personalizado com:

  • ✅ Banner personalizado em cima
  • ✅ Jogo embaixo em iframe
  • ✅ Controles personalizados
  • ✅ Interface editável
  • ✅ Botão para abrir original se quiser

🔧 Controles Disponíveis

No template personalizado você terá:

  • 🔍 Tela Cheia: Coloca o jogo em tela cheia
  • 🔄 Recarregar: Recarrega o jogo
  • 🌐 Abrir Original: Abre o jogo original do Gamezop

💻 Código da Implementação

O que mudou no games-config.js:

function playGame(gameId) { const game = getGameById(gameId); // TODOS os jogos agora abrem no template vertical personalizado const params = new URLSearchParams({ url: game.path, title: game.title, description: game.description, orientation: game.orientation, return: window.location.href }); window.location.href = `jogo-vertical-template.html?${params.toString()}`; }
