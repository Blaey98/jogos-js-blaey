# Implementação AMP - Portal de Jogos

## ✅ Implementado

### Arquivo Criado
- **`index.amp.html`** - Versão AMP da página inicial

### Código Implementado

#### 1. Script no `<head>`
```html
<script async custom-element="amp-auto-ads"
        src="https://cdn.ampproject.org/v0/amp-auto-ads-0.1.js">
</script>
```

#### 2. Código após `<body>`
```html
<amp-auto-ads type="adsense"
        data-ad-client="ca-pub-7154773731438541">
</amp-auto-ads>
```
