# 🎮 Portal de Jogos Navegador

Este projeto contém 3 páginas principais para jogos navegador, baseadas na configuração Flutter fornecida.

## 📁 Arquivos Criados

### 1. **js/game-config.js**
- Configuração JavaScript convertida do Flutter
- Contém todos os jogos com suas orientações e URLs
- Métodos para filtrar jogos por orientação

### 2. **jogos-verticais.html**
- Página para jogos otimizados para dispositivos móveis
- Banner de anúncio 320x100 no topo
- Layout responsivo com grid de jogos

### 3. **jogos-horizontais.html**
- Página para jogos otimizados para desktop/paisagem
- Banner de anúncio rotacionado 90° na lateral direita
- Layout adaptado para jogos horizontais

### 4. **lista-jogos.html**
- Página com lista completa de todos os jogos
- Sistema de busca e filtros
- Estatísticas dos jogos
- Interface completa com controles avançados

## 🌐 Links Localhost

Para acessar as páginas localmente, use os seguintes links:

### Página Principal (se existir index.html)
```
http://localhost:3000/
```

### Jogos Verticais
```
http://localhost:3000/jogos-verticais.html
```

### Jogos Horizontais
```
http://localhost:3000/jogos-horizontais.html
```

### Lista Completa de Jogos
```
http://localhost:3000/lista-jogos.html
```

## 🚀 Como Usar

1. **Inicie um servidor local** (ex: `python -m http.server 3000`)
2. **Acesse os links localhost** listados acima
3. **Navegue entre as páginas** usando os botões "Voltar"
4. **Clique em "Jogar Agora"** para abrir os jogos em nova aba
